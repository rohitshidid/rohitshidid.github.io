PromptLint

PromptLint is a FastAPI service with a plain HTML website that grades a prompt and picks the cheapest model good enough to answer it. Each prompt goes to the Jev judge (TypeSafe) in one call with 18 questions; if Jev is unavailable, a keyword heuristic answers instead. Ordinary code turns those probabilities into a Lint Score, PQS score, checklist, tips and cost estimates, and router.py picks a model tier, a cheapest candidate and a backup. With /v1/route and a saved provider key, providers.py can also send the prompt to OpenAI, Anthropic, Gemini or an OpenAI-compatible endpoint. Accounts, hashed API keys and usage counts live in Postgres (Neon in production).
