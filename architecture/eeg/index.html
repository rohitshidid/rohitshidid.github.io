EEG Independent Component Classification

This project decides whether an EEG independent component (IC) is an artifact, using a stacked ensemble. Each IC from the Zenodo dataset is read as three views: a 67x67 topoplot, a 90-bin power spectral density, and a raw time series. Each view trains its own Keras CNN, and a Random Forest is trained on statistical features of the time series. The base models' probabilities are saved and stacked (temporal CNN + RF merged first by logistic regression). Meta-learners (SVC, logistic regression, a small neural net) then make the final decision.
