Murmur — On-Device Dictation

Architecture diagrams generated from the source code

Murmur is a push-to-talk dictation app for macOS, written in Swift. Holding a hotkey (watched by a CGEventTap) starts microphone capture, and the audio streams in order to an on-device speech engine: Apple's SpeechAnalyzer or Parakeet running on CoreML through FluidAudio. When the key is released, the transcript goes through a rule-based structure pass (retraction, spoken commands, lists, email shape), optional on-device cleanup with Apple Foundation Models, and the user's dictionary. The result is then typed into the focused text field through the Accessibility API, or pasted if that fails. A floating overlay shows the live transcript and never takes focus.
