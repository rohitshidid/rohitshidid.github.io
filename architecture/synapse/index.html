Synapse (OpenRouter Chatbot)

Synapse is a small Node.js app with no dependencies that answers "which of these two answers is right?" questions. The browser sends the question and two options to server.js, which adds the OpenRouter API key on the server, locks the model to openrouter/free, and turns on OpenRouter's web-search plugin. The reply comes back as a JSON verdict with citations, and app.js shows it as a verdict card. The free model costs nothing; only web search is billed.
