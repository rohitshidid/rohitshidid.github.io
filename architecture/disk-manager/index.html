How it works

Disk Manager is a macOS disk-usage explorer: an Electron shell starts a local Node HTTP server (token-protected) and loads its vanilla-JS UI. Scans run ncdu on /System/Volumes/Data; the export is tailed into a typed-array TreeStore that powers the list, treemap, junk and duplicate finders. Deletes are screened by safety.js and then either renamed into a reversible bin (with undo/redo and a manifest), sent to the macOS Trash, or erased, with one admin prompt per batch when root is needed.
