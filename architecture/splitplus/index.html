Splitplus

Architecture diagrams generated from the source code

Splitplus is a group expense-splitting app built as a static Next.js export with no server of its own. All accounts, groups and expenses live in one Google Sheet behind a Google Apps Script web app; the browser talks to it through StorageService, writing to a localStorage cache first so the app opens instantly and works offline. Every page polls GET_USER_DATA every 20 seconds, and membership and expense writes run under an Apps Script lock so concurrent edits do not clobber each other.
