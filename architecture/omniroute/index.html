OmniRoute Chat Suite

This project is a set of clients for a self-hosted OmniRoute LLM gateway (an OpenAI-compatible router on localhost:20128). A small FastAPI app (app.py) deployed on Render serves a showcase page and a fixed model catalog; the web page itself does not call the gateway. For real chats, chat.py is a terminal REPL built on omniroute_client.py. The Claude-OmniRoute launcher checks the gateway, probes for a model that supports tool calls, and starts omnishim.py, a proxy that renames model IDs so Claude Code's /model picker can use OmniRoute models, then translates them back on each request.
