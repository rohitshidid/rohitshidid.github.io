AirControl

Architecture diagrams generated from the source code

AirControl lets you scroll, point and click a web page with hand gestures from your webcam. It is a single static index.html: MediaPipe's HandLandmarker (loaded from a CDN on first use) finds 21 hand landmarks in each video frame directly in the browser, and a requestAnimationFrame loop smooths them, classifies the pose, and only acts once the pose has held for a few frames. No video ever leaves the device.
