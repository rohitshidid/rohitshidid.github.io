How it works

Bandageboard is a Next.js 14 app that helps billers triage Medicare Part B wound-care claims. Vercel Cron (or the Sync button) calls /api/sync, which pulls patients, diagnoses, coverage, notes and assessments from the PCC API with 429-aware retries and upserts them into PostgreSQL via Drizzle. On each GET /api/eligibility, wounds are extracted (regex/JSON parsers, optionally Claude on de-identified text), deterministic rules route each claim to auto_accept / flag_for_review / reject, biller overrides are applied, and only masked results reach the dashboard; a local Ollama model explains decisions on demand.
