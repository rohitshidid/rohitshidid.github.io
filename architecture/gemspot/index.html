GemSpot Training

This subsystem trains the GemSpot will_visit classifier. export_training_data.py pulls the batch-pipeline Parquet from MinIO and writes train.csv / val.csv. src/train.py expands the list-encoded columns into 85 features and trains every candidate in configs/candidates.yaml (a dummy baseline, HistGradientBoosting, and two XGBoost variants), logging each run to MLflow. quality_gate.py then checks F1, AUC, precision, recall and the baseline margin, registers the best passing run as GemSpotWillVisit in Staging, and retrain_pipeline.py hands that model to the canary deploy script.

  • System architectureData sources, the training container, MLflow tracking and registry, the quality gate, and the optional Ray Tune cluster.
  • Workflow: retrain_pipeline.pyThe five orchestrated steps, plus the abort and keep-current-model stop conditions.
