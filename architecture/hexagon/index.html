Hexlandia (Hexagon)

Architecture diagrams generated from the source code

Hexlandia is a Catan-style board game for 2–10 players that runs in the browser. A single Node.js server (Express for static pages, the ws library for real-time messages) keeps every room in an in-memory map and owns the authoritative Game engine: clients only send intents such as "build a road", and the engine validates each one before broadcasting a personalised state view to every player. Bots are driven server-side on a 750 ms timer, and a reload reconnects the player to the same seat via a session id stored in localStorage.
